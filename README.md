# Orca plugins

Plugins for [Orca](https://onorca.dev) by Nithin Paul.

| Plugin | What it does |
|---|---|
| [Tmux Subagent Viewer](plugins/tmux-subagent-viewer) | See, message and drive your Claude Code subagents from Orca's right sidebar. macOS and Linux; needs tmux and Claude Code's tmux teammate mode. |

## Install

In Orca: **Settings → Plugins**, search the community directory, or add this repository as a marketplace:
`https://github.com/NithinPaul1360/orca-plugins.git`, ref `main`.

From the command line:

```sh
orca plugin install nithinpaul1360.tmux-subagent-viewer
```
